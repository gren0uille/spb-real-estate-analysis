# Анализ рынка недвижимости Санкт-Петербурга и Ленинградской области

## О проекте
Анализ данных рынка недвижимости СПб и Ленинградской области для агентства недвижимости.
Цель — определить самые привлекательные сегменты по времени активности объявлений,
выявить сезонные закономерности и факторы влияния на цену квадратного метра.

[Ссылка на интерактивный дашборд DataLens](https://datalens.yandex/m95x9vbdyw7q7)

## Задачи
- Сегментировать объявления по времени активности и выявить ключевые сегменты
- Проанализировать сезонную динамику публикаций и снятий объявлений
- Определить факторы влияния на стоимость квадратного метра и время продажи

## Ключевые результаты
- Сегментировал **23 650 объявлений** по времени активности через расчёт перцентилей
  (PERCENTILE_CONT/DISC): выявлено, что **25% объявлений** находятся на рынке более
  6 месяцев — определены приоритетные сегменты для работы агентства
- Обнаружил пики рыночной активности в **октябре, ноябре и феврале** через анализ
  сезонности с оконными функциями (ROW_NUMBER) — дало основу для планирования
  рекламных бюджетов под периоды высокого спроса
- Показал прямую зависимость цены от метража и выявил портрет типичного объекта:
  **2-комнатная квартира 55–60 кв.м с 1 балконом**, стоимостью **108–114 тыс. руб./кв.м**
- Средний ценовой сегмент Петербурга превышает ЛенОбласть на **40–45 тыс. руб./кв.м**

## Стек
SQL (PostgreSQL, CTE, оконные функции, PERCENTILE_CONT/DISC),
Python (Pandas, Matplotlib), Yandex DataLens
